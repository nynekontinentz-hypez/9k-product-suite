# MSP Playbook: Dental Practices

**Target:** 5–25 seat dental offices in Florida  
**Average deal size:** $1,200–3,600/mo  
**Buying triggers:** HIPAA compliance, practice management software, patient data security

---

## 1. The Dental Tech Stack

| Category | Recommended | Why |
|----------|-------------|-----|
| Practice Mgmt | Dentrix, Eaglesoft, Open Dental | Must support their existing system |
| Imaging | Dexis, Carestream | Integration with practice mgmt |
| Patient Comm | Lighthouse 360, Solutionreach | Often broken or mismanaged |
| Backup | Veeam + offsite | HIPAA requires 3-2-1 |
| Security | Bitdefender, DNS filtering | Protect PHI (Protected Health Info) |
| Compliance | HIPAA audit tool | Annual requirement |

## 2. Pain Points (Your Sales Angle)

1. **"My last IT guy quit and I haven't had support in 3 months"** → Offer rapid onboarding + 24hr response SLA
2. **"We had a ransomware scare last year"** → Pitch proactive security monitoring + offline backups
3. **"The front desk can't get Dentrix to print to the insurance printer"** → Standardized workstation imaging
4. **"I'm not sure if we're HIPAA compliant"** → Free HIPAA readiness assessment (lead magnet)
5. **"New hygienist starts Monday and needs a workstation"** → Offer pre-imaged hot-swap workstations

## 3. HIPAA Compliance Checklist (Deliverable)

Offer this as a free PDF download in exchange for email:

- [ ] Risk analysis completed (annually)
- [ ] BAAs signed with all vendors
- [ ] Encryption enabled on all devices
- [ ] Access logs reviewed (monthly)
- [ ] Employee training completed (annually)
- [ ] Backup tested (quarterly)
- [ ] Patches up to date
- [ ] Security policies documented
