# MSP Playbook: Real Estate Teams

**Target:** 3–20 person real estate teams and brokerages in Florida  
**Average deal size:** $800–2,500/mo  
**Buying triggers:** CRM migration, transaction management, lead follow-up automation

---

## 1. The Real Estate Tech Stack

| Category | Recommended | Why |
|----------|-------------|-----|
| CRM | Follow-up Boss, kvCore, BoomTown | Central to their operations |
| Transaction Mgmt | Skyslope, Dotloop, zipForms | Must work reliably |
| MLS Access | Local MLS system | Browser/email integration |
| Communication | Outlook/Google Workspace | Email deliverability critical |
| Lead Gen | Zillow, Realtor.com, custom IDX | Website integration |
| Backup | Cloud backup + local NAS | Lost deal data = lost money |

## 2. Pain Points (Your Sales Angle)

1. **"My CRM keeps crashing when I import leads"** → CRM optimization package
2. **"I need to access files from my phone while showing houses"** → Mobile-first setup
3. **"My email keeps going to spam"** → Email deliverability audit + DKIM/SPF setup
4. **"I just hired 5 new agents and need them set up yesterday"** → Rapid onboarding package
5. **"I'm not sure my transaction docs are backed up"** → Cloud backup assessment
