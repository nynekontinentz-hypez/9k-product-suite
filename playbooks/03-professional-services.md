# MSP Playbook: Professional Services

**Target:** 5–50 person law firms, accounting firms, and consultancies  
**Average deal size:** $1,500–6,000/mo  
**Buying triggers:** Compliance, data security, specialized software support

---

## 1. Overview

Professional services firms (law, accounting, consulting) have the highest willingness to pay for IT services in the SMB market. They handle sensitive client data and face regulatory requirements that make cheap/DIY IT a non-starter.

## 2. Vertical Sub-Targets

### Law Firms
- **Pain points:** Document management, billing software, client data confidentiality, e-discovery
- **Compliance:** ABA Model Rules, state bar requirements
- **Key apps:** Clio, MyCase, PracticePanther, NetDocuments, iManage, Worldox
- **Avg deal:** 10–25 users @ $149–$219/user/mo

### Accounting Firms
- **Pain points:** Tax season reliability, sensitive financial data, multi-factor auth requirements
- **Compliance:** IRS safeguards, AICPA, SOC reports
- **Key apps:** QuickBooks, Xero, Drake, UltraTax, CCH, Thomson Reuters
- **Avg deal:** 5–15 users @ $149–$219/user/mo

### Consulting Firms
- **Pain points:** Remote collaboration, client portals, proposal management
- **Key apps:** Salesforce, HubSpot, Deltek, Unanet, Microsoft 365
- **Avg deal:** 5–50 users @ $89–$149/user/mo

## 3. Compliance-Driven Sales

**The compliance conversation converts.** Lead with it:

```
Ask: "How do you handle client data confidentiality?"

They should mention: encryption, access controls, 
audit logs, secure disposal.

If they can't answer all four, you've found 
the pain point.
```

**Free compliance assessment offer:**
- 30-min call + 1-page report
- Covers: encryption, backup, access control, vendor management
- Follow-up with proposal for fixes

## 4. Service Package

**Professional Services Essential — $149/user/mo (min $750/mo)**

- Helpdesk with 2hr P1 response
- Specialized software support (Clio, QuickBooks, etc.)
- Client data security monitoring
- Encrypted backup (cloud + local)
- Business continuity planning
- Monthly compliance summary

**Professional Services Pro — $219/user/mo (min $1,200/mo)**

- All Essential features
- 1hr P1 response
- On-site visits (up to 4/mo)
- Quarterly compliance audit
- Staff security training
- Fractional CTO: 4hrs/mo strategic consulting
- Vendor security review
